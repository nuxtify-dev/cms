## Module Options

Configure `@nuxtify/cms` build-time and collection behavior under `nuxtifyCms` in `nuxt.config.ts` (not `app.config.ts`):

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@nuxtify/cms'],
  nuxtifyCms: {
    content: {
      notes: {
        enabled: false,
      },
      docs: {
        enabled: true,
        routePrefix: '/docs',
      },
    },
  },
})
```

> **Note:** Options that control routing, sitemap exclusions, and content parsing—such as `enabled` and `routePrefix` on `articles`, `notes`, `topics`, `contributors`, `tags`, and `docs`—must be set under `nuxtifyCms` in `nuxt.config.ts`. Setting them in `app.config.ts` will not disable routes or exclude them from `sitemap.xml`.

### Docs Options (`nuxtifyCms.content.docs`)

- `enabled`: Enable or disable `/docs` routes and sitemap entries (`true` by default).
- `routePrefix`: Customize the base URL path (`'/docs'` by default).
- `toc`: Control right-sidebar visibility and heading title (`'On this page'`).
- `prevNext`: Enable or disable bottom Previous / Next pagination cards.

## Runtime App Config

Runtime presentation settings (such as `brand`, `navigation`, `footer`, `announcement`, and `credits`) live under `nuxtify` in `app.config.ts` and are merged with your `nuxtifyCms` defaults for `useNuxtifyConfig()`.

## Per-Page Frontmatter

Individual Markdown pages can opt out of specific widgets:

```yaml
---
title: Standalone Reference
toc: false
prevNext: false
---
```
