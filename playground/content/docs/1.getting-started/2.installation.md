## Package Setup

Install `@nuxtify/cms` in your Nuxt 4 project alongside `@nuxt/content`:

```bash
npm install @nuxtify/cms
```

## Register the Module

Add `@nuxtify/cms` to your `nuxt.config.ts` modules array and register the `docs` collection inside `content.config.ts` using `docSchema`.

### Configure Collections

Ensure your `content.config.ts` defines a `docs` collection sourcing `docs/**` with `type: 'page'` and `schema: docSchema`.
