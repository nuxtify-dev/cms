## Overview

Nuxtify CMS (`@nuxtify/cms`) pairs **Nuxt Content v3** with clean **Vuetify 3** building blocks so you can publish marketing pages, editorial content, and structured documentation from plain Markdown files.

### Key Capabilities

- Automatic category tabs and sub-category sidebar generation from folders
- Sticky **On this page** Table of Contents (`h2` and nested `h3`) with scrollspy tracking
- Previous and next pagination cards across categories
- Draft filtering in production builds and automatic Schema.org structured data

### Zero-Config Defaults

Place Markdown files inside `content/docs/` and configure your collection with `docSchema` in `content.config.ts`. Every component can be customized by overriding the corresponding component in your app.

## Architecture and Conventions

Documentation follows standard `@nuxt/content` conventions where numeric prefixes control ordering without appearing in final URLs.

### Category Folders

Top-level folders inside `content/docs/` become main category tabs at the top of the docs view, and their `.navigation.yml` metadata controls display titles and icons.

### Table of Contents

Headings (`##` and `###`) are automatically indexed into the right sidebar so readers can jump directly to any section.

## Modular Design

Because every layout piece (`DocsTabs`, `DocsSidebar`, `DocsTitle`, `DocsPrevNext`, `DocsMobileBar`, and `PageToc`) is auto-registered, host applications can replace individual parts without ejecting the routing layer.
