## Using `.navigation.yml`

Place a `.navigation.yml` file inside any category or subgroup folder to control its label and icon without altering file names.

### Ordering Prefixes

Numeric prefixes such as `1.getting-started` and `2.guide` set display order while Nuxt Content strips numbers from public URLs.
