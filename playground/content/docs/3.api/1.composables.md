## Navigation Queries

### `usePublicCollectionNavigation`

Wraps `@nuxt/content`'s `queryCollectionNavigation` and excludes `draft: true` items when building for production.

### `usePublicCollectionSurroundings`

Wraps `queryCollectionItemSurroundings` with the same production draft safeguard for Previous / Next pagination.

## Schema.org

### `useDocSchema`

Generates structured `TechArticle` (or custom `schemaType`) and `BreadcrumbList` nodes from documentation frontmatter.
