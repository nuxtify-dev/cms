## Documentation Components

- `DocsTabs`: Sticky top horizontal tabs for main documentation categories.
- `DocsSidebar`: Left navigation sidebar supporting flat items and collapsible nested groups.
- `DocsMobileBar`: Sticky mobile action bar with drawer menu and expandable inline TOC.
- `DocsTitle`: Breadcrumbs, page heading, description subtitle, and divider.
- `DocsPrevNext`: Previous / Next pagination cards at the bottom of a page.

## Page Components

### `PageToc`

Reusable sticky `"On this page"` Table of Contents with `h2`/`h3` hierarchy and `IntersectionObserver` scrollspy tracking.
